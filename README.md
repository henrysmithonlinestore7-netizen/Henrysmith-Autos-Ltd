# HenrySmith Autos Ltd - Business Banking Platform

## 📋 Project Overview

HenrySmith Autos Ltd is a comprehensive business banking solution designed specifically for automotive businesses and merchants in Nigeria. The platform provides integrated financial management tools, card services, and transaction handling.

## 🏗️ Project Structure

```
Henrysmith-Autos-Ltd/
├── src/
│   ├── pages/
│   │   └── dashboard.html          # Main dashboard interface
│   ├── config/
│   │   ├── database.py             # Database and bank configurations
│   │   └── settings.py             # Application settings
│   └── assets/                     # Static resources (CSS, JS, images)
├── docs/                           # Documentation files
├── README.md                       # Project documentation
├── LICENSE                         # Boost Software License 1.0
└── .gitignore                      # Git ignore rules
```

## ✨ Features

- **Dashboard**: Real-time account overview and balance display
- **Money Transfer**: Quick and secure fund transfers between accounts
- **Airtime & Bills**: Purchase airtime and pay utility bills
- **Account Statements**: Detailed transaction history and statements
- **Merchant Debit Cards**: Request and manage merchant debit cards
- **Security**: Advanced security features including 256-bit SSL encryption
- **Settings**: User profile and account management
- **Multi-Bank Support**: Integration with 12+ Nigerian banks

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- Web browser (Chrome, Firefox, Safari, Edge)
- Internet connection

### Installation

1. Clone the repository:
```bash
git clone https://github.com/henrysmithonlinestore7-netizen/Henrysmith-Autos-Ltd.git
```

2. Navigate to project directory:
```bash
cd Henrysmith-Autos-Ltd
```

3. Install dependencies (if applicable):
```bash
pip install -r requirements.txt
```

### Running the Application

1. Open the dashboard:
```bash
open src/pages/dashboard.html
```

Or navigate to the file in your web browser.

## 📱 User Interface

### Dashboard Components

- **Navigation Bar**: Quick access to all features
- **Account Balance**: Real-time balance display
- **Card Management**: View and manage merchant debit cards
- **Recent Transactions**: Quick view of latest transactions
- **Supported Banks Grid**: Browse available banking partners

## 🔧 Configuration

Edit configuration files in `src/config/` to customize:

- `settings.py`: UI themes, pagination, features
- `database.py`: Bank integrations, account types
