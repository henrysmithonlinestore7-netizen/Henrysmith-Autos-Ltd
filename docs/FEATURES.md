# HenrySmith Autos Ltd - Features Documentation

## Core Features

### 1. Dashboard
- Real-time account balance display
- Quick access to all features
- Transaction summary
- Account overview

### 2. Money Transfer
- Send funds to other accounts
- Select recipient bank
- Enter transfer amount
- Add transfer narration/description
- Secure PIN verification

### 3. Airtime & Bills
- Purchase mobile airtime
- Pay utility bills
- Track bill payments
- Transaction confirmation

### 4. Account Statements
- View transaction history
- Filter by date range
- Export statements
- Transaction details

### 5. Merchant Debit Cards
- Request new debit cards
- View active cards
- Card details (holder name, expiry, type)
- Card management options

### 6. Security Settings
- PIN management
- Account security settings
- Login history
- Device management

### 7. Account Settings
- Profile information
- Business details
- Account preferences
- Notification settings

## Transaction Types

- **Debit**: Money going out
- **Credit**: Money coming in
- **Transfer**: Fund transfers between accounts
- **Payment**: Bill payments and services

## Card Types

- Visa Debit Card
- MasterCard Debit Card
- Local Debit Card
- Business Debit Card

## Security Features

- 256-bit SSL Encryption
- Secure PIN Authentication
- Transaction Verification
- Account Lockout Protection
- Fraud Detection
- NDIC Insurance Coverage
